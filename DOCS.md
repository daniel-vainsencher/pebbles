## 🎓 Learning Path

### Level 1: Basic Usage (30 min)
1. Skim [README.md](README.md)
2. Follow the installation
3. Try the Quick Example in [README.md](README.md)
4. Bookmark [QUICKSTART.md](QUICKSTART.md)

### Level 2: Productive User (1 hour)
1. Read [QUICKSTART.md](QUICKSTART.md) fully
2. Work through [EXAMPLES.md](EXAMPLES.md)
3. Try your own workflow
4. Reference [STATUS.md](STATUS.md) for features

### Level 3: Power User (2 hours)
1. Read all of [EXAMPLES.md](EXAMPLES.md)
2. Understand [DESIGN.md](DESIGN.md)
3. Know all features from [STATUS.md](STATUS.md)
4. Create custom workflows

### Level 4: Contributor (4 hours)
1. Understand [ARCHITECTURE.md](ARCHITECTURE.md)
2. Read [PROGRESS.md](PROGRESS.md) for TODOs
3. Review [SUMMARY.md](SUMMARY.md) for decisions
4. Follow patterns in existing code
